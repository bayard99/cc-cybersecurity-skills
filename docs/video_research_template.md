> Target time to complete: 30–45 minutes.
> If you can't fill 80% of it confidently, the video isn't ready yet.

## 2. The Audience Question

**Who is this video for?** Be specific. Not "developers." Not "cybersecurity people."

- [ ] Primary viewer: _e.g., a small business owner curious about AI security tools_
- [ ] What do they already know? _e.g., basic AI awareness, no coding background_
- [ ] What problem are they sitting with right now? _e.g., they got a suspicious email this week_
- [ ] Why would they click THIS video over the 10 alternatives? _e.g., it's the only one that actually builds the tool with them_

> ⚠️ If you can't answer #4 in one sentence, the angle isn't sharp enough.

## 3. Keyword Research

Do these 4 searches before writing anything:

### Search A: The literal topic
- Query: `_______________`
- What dominates the results? (corporate SEO / individual creators / news / academic)
- Top 3 videos and their view counts:
  1. ___ — _views_
  2. ___ — _views_
  3. ___ — _views_

### Search B: The "how to build" version
- Query: `how to build _______`
- Tutorial supply: heavy / moderate / light / none
- Quality of existing tutorials: high / mid / low

### Search C: The trending angle
- Is there a news event / new tool / new model people are searching for right now?
- Query: `_______ 2026`
- Trend: rising / flat / declining

### Search D: The adjacent buyer pain
- What do worried, non-technical people Google? (e.g., "is this email a scam")
- Where do those searches go? (Reddit, Quora, vendor sites, YouTube)
- Is there a gap a tutorial video could fill?

**Verdict:**
- [ ] Green field (low competition, real demand) → proceed
- [ ] Crowded but I have a sharper angle → proceed with care
- [ ] Saturated, no fresh angle → pick a different topic

## 5. The Hook (write 3 variants, pick best)

The first 5 seconds decide everything. Write three hook openings as if you're saying them out loud:

1. _Hook A — story-driven:_ "Last week, a [type of person] lost [$X] to a phishing email that looked like..."
2. _Hook B — challenge-driven:_ "I gave Claude one job: catch every phishing email I receive for a week. Here's what happened."
3. _Hook C — claim-driven:_ "In 30 minutes I built a tool that catches phishing emails better than my company's filter. Here's how."

> **Pick the one that survives a 10-second test:** read it aloud. Does it make YOU want to keep watching? If no, rewrite.

## 7. Thumbnail Brief

Thumbnails decide 60% of CTR. Don't skip.

- [ ] **Text overlay** (3–5 words max): ___
- [ ] **Face expression**: surprised / focused / pointing / neutral
- [ ] **Primary visual element**: code window / terminal / a specific scary-looking email / before-after split
- [ ] **Background mood**: dark + accent color / clean + bright / red-alert tones
- [ ] **One bold contrast**: red circle on key element / arrow / split-screen
- [ ] **Mobile readability check**: can you read the text at 200px wide?

Sketch this in Canva BEFORE recording. The thumbnail decides the title, not the other way around.

## 9. Structure Outline

A build video has 5 beats. Write 1–2 lines per beat:

1. **Hook (0:00–0:15)** — the 15-second open from §5
2. **Problem setup (0:15–1:30)** — why this matters, who this is for
3. **The build (1:30–8:00)** — show, narrate, show the struggle moments
4. **Demo (8:00–11:00)** — test it live on real examples
5. **CTA + payoff (11:00–end)** — "install it in 30s, here's the command, subscribe"

> Don't write a script word-for-word. Write bullets. Let yourself talk.

## 11. Distribution Plan (after publish)

For every long video, ship:

- [ ] 2 YouTube Shorts cut from the long (best 30–60s moments)
- [ ] 1 LinkedIn post — "I built X this week, here's what I learned"
- [ ] 1 Twitter/X thread — 6–8 tweets walking through it
- [ ] 1 Newsletter issue — long-form version with the install link
- [ ] 1 Reddit post in r/cybersecurity or r/ClaudeCode (genuine, not spammy)
- [ ] GitHub release notes filled in properly

> One creation, six channels. Do this BEFORE you start work on video #N+1.

## 12. Self-Check (before hitting record)

- [ ] I can state the promise of this video in one sentence
- [ ] My hook makes ME want to keep watching
- [ ] My title would make me click if I saw it in my feed
- [ ] The skill works end-to-end on a fresh machine
- [ ] I have 5+ test cases ready for the live demo
- [ ] The thumbnail is sketched, not just imagined
- [ ] The distribution plan is queued up

If any of these are unchecked, you're not ready. Don't record yet.
